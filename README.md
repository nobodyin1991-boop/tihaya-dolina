# Тихая долина — Кольцо караванов

Одиночная 3D action-RPG: три города, торговое кольцо, караваны, которые вы снаряжаете и лично ведёте через разбойничьи засады и логова чудовищ.

## Запуск

- **Двойной щелчок по `Играть.cmd`** — игра открывается в отдельном окне и всегда использует дискретную видеокарту.
  F11 — полный экран, F12 — инструменты разработчика.
- `npm run gpu-check` — запускает игру на несколько секунд и печатает, на какой видеокарте она работает.
- `npm run web` — вариант для браузера: http://127.0.0.1:5180 (браузер сам выбирает видеокарту).
- `npm test` — тесты игровой логики.

Сохранение автоматическое (каждые 20 секунд и при выходе). Экспорт и импорт сохранения — в меню Esc → «Система».
Качество графики (низкое / среднее / высокое / ультра) — Esc → «Настройки»; смена качества перезапускает мир.

| Действие | Клавиша |

| Движение | WASD |
| Обзор | мышь, колесо — дистанция камеры |
| Бег / шаг | Shift / Caps Lock |
| Прыжок | Пробел |
| Перекат (неуязвимость на миг) | ПКМ или Ctrl |
| Атака | ЛКМ (удерживать) |

| Быстрые предметы | 6–9, Q — лучшее лекарство |
| Выбор цели | Tab |

| Сумка / персонаж / умения / ремесло | I / C / K / P |
| Журнал / карта / караван | J / M / L |
| Меню | Esc |

## Как устроена игра

1. **Готовьте груз.** Интендант города ведёт ведомость: сырьё, изделия мастеров, провизия. Добывайте, мастерите, покупайте.
2. **Снаряжайте караван.** У конюха — телега и её улучшения, у капитана стражи — наёмники. В свободное место грузите свои товары: в городе назначения они стоят дороже.
3. **Разведайте дорогу.** Зачищенный лагерь разбойников или сделка с атаманом убирают засады на тракте.
4. **Ведите телегу.** Она едет, пока вы рядом и путь свободен. Засады, мародёры, завалы, сломанное колесо, гнилой мост.
5. **Три этапа:** Тихая долина → Каменный Брод → Янтарная Гавань → обратно в долину старой южной дорогой. Каждый этап длиннее и опаснее. Потом открываются гильдейские подряды.

Рост героя — как в «Готике»: за уровень дают очки обучения, а тратить их нужно у наставников в городах (характеристики, ранги умений, таланты).
